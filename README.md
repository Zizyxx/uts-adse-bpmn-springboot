# Proyek UTS ADSE: Otomasi Alur Pengajuan Skripsi Mahasiswa dengan Spring Boot & Camunda BPMN

Implementasi sistem workflow BPMN 2.0 menggunakan Camunda Platform 7 Engine dan Spring Boot Framework.

## Cara Menjalankan
1. Compile & run:
   mvn clean spring-boot:run
2. Buka Camunda Webapps di browser:
   - URL: http://localhost:8080/camunda
   - User: admin
   - Pass: adminpassword
